## 引脚分配（8 引脚，全部用尽）

| 引脚 | 功能 | 方向 | 说明 |
|------|------|------|------|
| P3.2 | INT0 按键 | 输入 | 下降沿触发，唤醒 STOP 模式（中间操作开关） |
| P3.3 | ADC3 光照 | 模拟输入 | 接光传感器分压点，高阻抗 |
| P5.4 | I2C SDA | 开漏输出 | 连接 OLED SDA |
| P5.5 | I2C SCL | 开漏输出 | 连接 OLED SCL |
| VCC | 电源 | 输入 | 3.7V 锂电池直接供电给 MCU 与 OLED |
| GND | 地 | 输入 | 公共地 |

> ?? 8 引脚 SOP-8 封装，全部用尽。中间操作开关负责唤醒与模式切换，侧边独立开关控制手电筒，互不干扰。
> 每一个引脚都在工作 — 按键唤醒、光照感知、OLED 显示，一个不少。
> 这就是极限开发 — 在最小的芯片上实现最大的功能。

## 光照传感器电路

```
        VCC (3.3V)
         │
        [2K]        ← 分压上臂
         │
    ─────┤───── P3.3 (ADC3)
         │
       [LDR]        ← 光敏电阻（暗态 ~100KΩ，亮态 ~1KΩ）
         │
        GND
```

- 暗态：LDR 阻值大，P3.3 电压高，ADC 值大
- 亮态：LDR 阻值小，P3.3 电压低，ADC 值小
- 代码中使用带隙基准（1.19V）做比率补偿，消除电池电压漂移

### 阈值

光照判断阈值为补偿后 ADC 值 **3096**（4096 满量程），日光下约 2000+，荧光灯下约 500-800。超过阈值认为光照充足。

## 手电筒电路说明（独立开关控制）

原设计中 LED 与按键串联，导致两个问题：每次按键操作都会点亮 LED 增加功耗，且 LED 工作时的电流波动会干扰按键检测。因此将手电筒改为侧边独立开关供电：

```
 VCC (3.7V 锂电池)
         |
        [R_LED]  ← LED 限流电阻（建议 1kΩ，约 1~2 mA 驱动电流）
         |
        [LED]    ← 发光二极管（手电筒光源）
         |
        [SW]     ← 侧边独立开关（常开，手动控制）
         |
        GND
```

说明：手电筒与操作按钮完全解耦，各自独立工作。侧边开关直接控制 LED 通断，不经过 MCU，因此可以在任何状态下单独使用手电筒功能。

## 操作按钮电路说明（P3.2）

操作按钮仅用于 MCU 交互，电路简洁：

```
 P3.2 ────┬──── GND
         │
       [SW]     ← 中间操作按键（常开，按下接通）
```

不需要外部上拉电阻，MCU 内部上拉即可。

## OLED 连接

SSD1306 128×32 OLED 模块，I 2C 地址 `0x78`。

| OLED 引脚 | 连接 |
|-----------|------|
| VCC | 3.3V |
| GND | GND |
| SCL | P5.5（经上拉至 VCC） |
| SDA | P5.4（经上拉至 VCC） |

软件 I2C，无需硬件 I2C 外设。开漏输出 + 外部上拉（4.7KΩ 推荐）。



## 电源管理

| 状态 | 电流 | 说明 |
|------|------|------|
| 运行（OLED ON） | ~5mA | 显示 + MCU 运行 |
| STOP 待机 | ~5μA | MCU 深度休眠，OLED 关闭 |
| 唤醒恢复 | ~10ms | INT0 中断唤醒，重新初始化 |

- 待机时 ADC 关闭、OLED 电荷泵关闭
- 所有 GPIO 恢复准双向口模式（最低漏电）
- 唤醒后等待按键释放再初始化 OLED，防止按钮按住时电源塌陷

## EEPROM

片上 EEPROM 双备份存储：

| 地址 | 内容 | 大小 |
|------|------|------|
| 0x0000 | 备份槽 A | 5 字节 |
| 0x0010 | 备份槽 B | 5 字节 |

存储格式：`merit[4] + mode[1]`。写入时交替写两个槽，断电安全。启动时读取有效槽恢复数据。

## 供电方案：锂电池 + TP4057

### 为什么用锂电池？

作为一款要长期使用的设备，可充电锂电池比纽扣电池更实用：
- USB-C 充电，现代人手边都有线
- TP4057 充电管理芯片，安全可靠，成本仅 0.5 元
- 100mAh 锂电池，待机半年，日常使用绰绰有余

### 电池参数

| 参数 | 数值 |
|------|------|
| 类型 | 3.7V 锂聚合物电池 |
| 容量 | 100mAh |
| 充电接口 | USB Type-C |
| 充电管理 | TP4057（CC/CV） |
| 充满电压 | 4.2V |
| 放电截止 | 3.0V |
| 预计续航 | 半年以上（每天按 50 次） |

### TP4057 充电电路

```
USB-C VBUS (5V)
      │
      ▼
   ┌──────┐
   │TP4057│
   │      │──── CHRG (充电指示)
   │  OUT │──── STDBY (充满指示)
   └──┬───┘
      │
        3.7V ──┬── MCU + OLED (直接供电，请注意电压兼容性，详见下文)
                          │
                  锂电池
```

- TP4057：SOT-23-5 封装，充电电流可编程（默认 450mA）
- 充电时 CHRG 引脚拉低，可接 LED 指示
- 充满后 STDBY 引脚拉低，可接 LED 指示
- 输入端 0.1μF + 输出端 10μF 电容

注意：当前设计为电池直供 MCU 与 OLED。这意味着 MCU 与 OLED 将直接承受电池电压范围（约 4.2V 充满 → 3.0V 亏电）；请确保所用 MCU 与 OLED 模块在该电压范围内可靠工作，或在 PCB 版本中加入稳压或升降/降压转换方案以保证显示与 MCU 在全电量范围内的稳定性。

| 状态 | 电流 | 说明 |

| 运行（OLED ON） | ~5mA | 显示 + MCU 运行 |
