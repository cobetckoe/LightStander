# LightStander 使用说明

> **赌王不赌，股神不炒，让太阳做你的操盘手。**

## 它是什么？
你要站在光里，不要光站在那里

站光侠是一个掌心大小的随机决策器：把它带到阳光下，按一下按钮，它用光产生的硬件随机数显示一支股票代码或一个操盘建议。它不荐股、不分析——把决定交给太阳，让你从盯盘中抽身，换一种诚实又荒诞的决策方式。

## 快速上手
- 充电：USB-C 接口，充满一次约可用半年。
- 站到光里按一下中间按钮：光充足则显示 6 位股票代码或操盘策略，并记录一次“光功德”。
- 太暗？屏幕会提示“请站在光里”。走到阳光下是最正统的方案。但如果你正在地下室、深夜、或者阴天，还有一个**达文西式的解决方案**：打开另一台站光侠的侧边手电筒照射光敏电阻，等于用同类设备互相点亮。

## 模式与按键
- **按一次中间操作按钮**：触发当前模式的随机输出。
- **按住中间操作按钮不放**：切换模式（随机选股 / 意外操盘）。
- **侧边点动按钮**：按下点亮手电筒、松手熄灭（不保持），独立于主程序，可用来发送摩尔斯电码。

## 屏幕提示
一次完整操作依次经过三个页面：

1. **题目页（待机）**：居中显示当前题目 `随机选股` / `意外操盘`。
2. **结果页**：第一行保持题目，第二行显示本次结果。
   - `6 位数字`：随机股票代码。
   - `2 字`：随机操盘策略（补仓/空仓/平仓/减仓/半仓/建仓/加仓/持仓/满仓）。
3. **功德页**：第一行 `光功德+1`（本次已记录），第二行显示累计总功德。

其他提示：
- 整屏 `请站在光里`：光线不足，请移到阳光下。
- 整屏 `电池图标`：电量耗尽，设备将在约 1 秒后自动关机，请充电。

## 注意事项
- 本设备仅提供娱乐/随机建议，不构成投资建议。
- 确保在足够光线下使用，以获得更稳定的硬件随机性。
- 断电不丢失：设备会保存光功德与当前模式。

## 电池使用说明
- **充电**：USB-C 接口充电，内置 TP4057 充电管理芯片。
- **低电量保护**：设备在每次唤醒和每次按键时自动检测电池电压。当电压低于阈值时，屏幕会显示电池耗尽图标约 1 秒，然后设备直接关机，以保护电池不过度放电。
- **电池寿命**：100mAh 锂电池充满后可持续数十次操作，日常使用约半年充一次。
- **长期存放**：超过 3 个月不使用，建议充满电后存放。锂电池长期亏电可能永久损坏。
- **工作温度**：锂电池建议在 0°C~45°C 范围内使用，过低或过高温度均会影响性能。
