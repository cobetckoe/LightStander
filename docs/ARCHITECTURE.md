## 随机数设计

### LCG 后处理

物理熵源提供种子后，使用线性同余生成器 (LCG) 进行后处理，扩展为均匀分布的随机序列：

```
state = state × 0x9D65 + 0x3B7A
output = state ^ (state >> 8)
```

周期 65536，对本应用足够（每次按键只取一个值）。物理熵 + 数学变换的组合，兼顾了真正的随机性和均匀分布。

### 位图压缩算法

**5914 支股票，全部压缩进 ~5KB Flash。**

传统方法需要存储 5914 个 16-bit 股票代码 = 11,828 字节。而位图压缩仅用 5914 bits = 740 字节（每组前缀一个位图）。

**压缩比：16:1**。

算法原理：
- 每个股票前缀（如 600）对应一个位图数组
- 位图大小 = ?该前缀下最大股票后缀 / 8? 字节
- 每个 bit 代表一支股票：1=存在，0=不存在
- 查询时：`byte_idx = suffix >> 3`，`bit_idx = suffix & 0x07`
- 一个字节一次查表，零分支，零循环

```c
// 示例：bitmap_600 覆盖后缀 000-999 → 125 字节
// bitmap_600[0] 的 bit0 = 600000 是否存在
// bitmap_600[0] 的 bit1 = 600001 是否存在
// ...
// bitmap_600[124] 的 bit7 = 600999 是否存在

static uint8_t BitmapCheck(uint8_t code *bmp, uint16_t suffix) {
    uint8_t byte_idx = suffix >> 3;   // 除以8，定位字节
    uint8_t bit_idx  = suffix & 0x07; // 取余，定位位
    return (bmp[byte_idx] >> bit_idx) & 0x01;  // 一次移位+掩码
}
```

12 组位图覆盖全部 12 个股票前缀，查询速度 O(1)，代码量极小。

**这就是为什么 8KB 的 MCU 能装下整个 A 股市场。**

## 光熵随机数设计

LightStander 的核心设计理念是「以光为源」— 利用自然环境光作为随机数的物理熵源。

### 熵来源

光敏电阻（LDR）的阻值受光照强度影响而波动，这种波动包含大量不可预测的物理噪声：
- 光子到达的量子随机性
- 云层移动、树影摇曳等环境变化
- 人工光源的电磁干扰

ADC 采样这些波动并混入随机状态，使得每次开机、每次按下按钮的随机序列都不同。

### 种子生成

开机时采集 32 次 ADC 值，通过异或 + 循环移位混合生成种子：

```
for (i = 0; i < 32; i++) {
    seed ^= ReadLightADC();
    seed = (seed << 3) | (seed >> 13);  // rotate
}
```

每次选股前重新采集 8 次 ADC 混入状态（`ReSeedFromLight()`），确保每次按下按钮的随机性都包含最新的光照信息。

### 带隙基准补偿

电池电压随使用逐渐下降，直接影响 ADC 采样精度。STC8G1K08A 内置 1.19V 带隙基准电压，同时作为 ADC 采样通道（CH15），通过比率计算消除电压漂移：

```
compensated = light_reading × 1192 / bandgap_reading
```

无论电池是 3.3V 还是降到 2.8V，光照判断始终准确。

### 低功耗设计

```
运行态 ──button──? 唤醒 ──处理完──? STOP
  ↑                                    │
  └──────────── INT0 中断 ─────────────┘
```

1. **进入 STOP**：关闭 ADC、OLED 电荷泵、所有 GPIO 设为准双向
2. **唤醒**：INT0 下降沿触发，MCU 从 STOP 恢复
3. **恢复顺序**：等待按键释放 → 重新初始化 GPIO → 重新初始化 ADC/OLED

## EEPROM 存储

双备份策略防止断电丢数据：

```
写入: Slot A ← 新数据 → Slot B ← 新数据
读取: Slot A OK? → 用 A
       Slot B OK? → 用 B
       都无效 → 默认值(merit=0, mode=STOCK)
```

写入延迟：按键触发后不立即写入，而是在下一次进入 STOP 前批量写入（`FlushSave`），减少 EEPROM 磨损。
