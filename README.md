## 这是什么？

LightStander，**站光侠** — 一款外观 1:1 仿照今年最火的光模块设计的掌上小设备。

2026 年的 A 股市场，科技股疯狂炒作，光模块概念股涨了三倍五倍十倍。无数人冲进去，以为自己抓住了时代的红利，结果成了被割的韭菜。

站光侠不炒股，不荐股，不割韭菜。它只是用最硬核的方式告诉你一个真相：**你研究三天的K线图，可能不如太阳照一秒产生的随机数靠谱。那些喊你「抄底」「满上」的分析师，不会在你亏钱的时候替你买单。**

## 设计理念

### 为什么叫站光侠？

**「你要站在光里，不要光站在那里。」** —— 这是 2026 年股市流传最广的一句话。别人说这句话是在激励你行动，而站光侠说这句话，是让你**物理上真的站到光里**。

别人大喊「站在光里」的时候，心里想的是信心、勇气、不要犹豫。而你低头看了一眼手里的光模块，走到阳光下，按了一下按钮。你们都在「站在光里」，但你是唯一一个字面意义上做到了的。

当你站在阳光下，光线通过光敏电阻产生真实世界的物理熵 — 每一颗光子的到达都是量子级别的随机事件。这个随机数不听庄家的，不看K线图，不被任何力量操控。

**它是你在这个充满信息不对称的市场里，能获得的唯一真实的东西。**

### 关于「光功德」

每一次在阳光下按下按钮，光功德 +1。这不只是计数，这是一种仪式感：

- 站到阳光里 = 停止盯盘，去晒太阳
- 按下按钮 = 接受随机的命运
- 光功德 +1 = 你今天比 99% 的散户更清醒

> 光功德者，日光所积也。每一步走向阳光，都是一次与韭菜命运的决裂。

### 为什么是光模块外观？

因为讽刺。光模块今年被炒上了天，而这个小东西的外壳就是 1:1 仿照光模块的工业设计。拿在手里，别人以为你在搞什么高科技，其实你在晒太阳。

**让光模块的光，真正照进你的生活 — 而不是照进庄家的口袋。**

**赌王不赌，股神不炒。** 真正的高手，从不在赌桌上和概率较劲。他们知道，唯一确定的事就是不确定性本身。而站光侠，把这种确定的不确定性，装进了你的掌心。

## 功能

- **随机选股**：覆盖沪深两市 + 北交所共 **5914** 支 A 股，按真实上市数量加权随机
- **随机操盘**：补仓、空仓、平仓、减仓、半仓、建仓、加仓、持仓、满仓 9 种操盘策略
- **光照感知**：环境光不足时提示「请站在光里」，走到阳光下才能选
- **手电筒**：侧边独立开关控制，随时可用
- **光功德**：记录你在阳光下积累的清醒次数
- **超低功耗**：待机仅 5μA，一颗锂电池用半年

## 硬件

| 组件 | 型号 / 规格 |
|------|------------|
| MCU | STC8G1K08A（8KB Flash, 256B iRAM, 1K xRAM, 24MHz） |
| 显示 | SSD1306 OLED 128×32，软件 I2C（SCL=P5.5, SDA=P5.4） |
| 操作按钮 | P3.2 / INT0，下降沿触发，唤醒 MCU |
| 侧边开关 | 独立控制手电筒，与操作按钮完全解耦，避免待机耗电 |
| 光传感器 | P3.3 ADC3 + 2K 分压电阻 |
| 充电 | TP4057 锂电池充电管理，USB-C 输入 |
| 电池 | 3.7V 锂聚合物电池 100mAh，Type-C 充电 |

详细硬件设计请参阅 [docs/HARDWARE.md](docs/HARDWARE.md)。

## 操作

设备通电后自动进入待机，无需任何操作。

1. **按一次中间按钮**：唤醒设备，显示当前光功德值
   - 光照充足 → 随机显示一个股票代码或操盘策略，光功德 +1
   - 光照不足 → 显示「请站在光里」，请移动到更亮的位置
2. **按住中间按钮不放**：屏幕切换模式后松手（选股 ? 操盘）
3. **侧边开关**：独立控制手电筒，随时点亮，与主程序互不干扰

### 如果太暗了怎么办？— 达文西的太阳能手电筒

如果环境光线不足，设备会提示「请站在光里」。走到阳光下是最正统的方案。但如果你正在地下室、深夜、或者阴天，还有一个**达文西式的解决方案**：


打开另一台站光侠的侧边手电筒照射光敏电阻，等于用同类设备互相点亮。

是的，这听起来很荒谬 —— 用一台站光侠去照亮另一台站光侠。但仔细想想，它的逻辑是自洽的：**站光侠的光传感器需要光，另一台站光侠的手电筒有光，问题解决。**

> 这不是 bug，这是 feature。达文西的智慧，跨越时空，在一个掌上设备上得到了验证。

详细使用说明请参阅 [docs/USER_MANUAL.md](docs/USER_MANUAL.md)。

## 硬件设计哲学：物尽其用

> 一粒米养百样人，一KB 包万象物。

本项目的核心工程挑战是：**在 8KB Flash、256 字节 RAM 的极限空间内，塞进一个完整的股票随机系统。**

| 资源 | 总量 | 已用 | 利用率 |
|------|------|------|--------|
| Flash (Code) | 8192 B | ~8158 B | **99.6%** |
| iRAM | 256 B | 9 B | 3.5% |
| xRAM | 1024 B | 43 B | 4.2% |
| 引脚 | 8 (SOP-8) | **全部用尽** | 100% |

这是一颗只有 **8KB Flash、8 个引脚、售价不到 1 元**的 MCU。我们把它榨干了：

- **位图压缩**：5914 支股票用位图表示，1 bit = 1 支股票，12 组前缀压缩进 5KB
- **字模复用**：27 个 16×16 中文字模精打细算，每一个字位都被利用
- **软件 I2C**：没有硬件 I2C？用 GPIO 软件模拟，两根线搞定 OLED
- **带隙基准**：用芯片内置的 1.19V 基准做 ADC 补偿，省掉外部参考电压
- **STOP 模式**：待机 5μA，唤醒 10ms，一颗锂电池撑半年
- **双备份 EEPROM**：断电不丢数据，两个槽位交替写入

**每一个引脚都在工作，每一个字节都在发光。** 这就是极限开发的魅力。

## 开源二创：随机数的无限可能

站光侠的核心是一个**真正基于物理熵的随机数发生器**。光子的到达时间是量子级别的随机事件，这使得它产生的随机数比任何软件算法都更「诚实」。

我们鼓励大家基于这个硬件平台进行二创，开发更多奇葩用途

**任何需要「随机数」的场景，都可以交给站光侠。**

如果你做了一个有趣的二创项目，欢迎提交 PR 分享给大家。
