LightStander 站光侠 v1.0.0 — 固件发布

面向 STC8G1K08A (SOP-8) 的随机选股/操盘助持器。本发布为可直接烧录的
Intel HEX 固化件，由本仓库源码在 Keil C51 V9.60.7.0 下全量编译生成。

--------------------------------------------------------------------
烧录要求
--------------------------------------------------------------------

目标芯片      STC8G1K08A-8K/1K08 SOP-8（8 KB Flash, 256 B iRAM, 1 KB xRAM）
主频          24 MHz（内部 IRC，1T 8051）
Flash 布局    IROM 0x0000 - 0x1FFF
烧录工具      STC-ISP（AiCube-ISP）
固件大小      7714 / 8192 字节（94.2% 利用率，余量 478 字节）
              data=9.0  xdata=49

!!! 烧录后必须完全断电（拔电池或断 USB）等待 3 秒以上再上电 !!!

      这是 STC8G 系列的必要步骤。STC-ISP 结束烧录后单片机的复位流程
      不完整，ADC / IAP / STOP 模块可能残留异常状态，直接上电会表现
      为完全黑屏。断电冷启动后即恢复正常。

硬件接线
--------------------------------------------------------------------

  OLED  SSD1306 128x32，软件 I2C
        SCL = P55, SDA = P54, 从机地址 0x78
        I2C 必须外部上拉电阻（推荐 4.7KΩ 接 3.3V）
        SSD1306 最大 I2C 速率 400 kHz；本固件实际约 240 kHz

  ADC   光照检测 / 电池电压分压输入（10 位 ADC，满量程 1023）
        光照阈值 1015 对应分压上臂 100KΩ；换板需按实机重新标定
        电池低压阈值 420，约合 VDD 2.90 V

  按键  外部中断 + 数字端口输入，消抖与长按检测

  电源  OLED 建议稳压供电，不要直连电池满电 4.2V

--------------------------------------------------------------------
功能
--------------------------------------------------------------------

  随机选股   12 组前缀权重分布，共 5914 支候选代码，随机后缀 + 位图校验
  随机操盘   9 种仓位动作
  光功德     阳光下每完成一次操作累计 +1，EEPROM 双槽备份，掉电不丢
  低光保护   光照不足时显示「请站在光里」并返回待机
  低压保护   低于约 2.90 V 显示电池图标后关机
  低功耗     STOP 模式待机，按键中断唤醒
  持久存储   片上 EEPROM 双槽备份，含槽位合法性校验
  显示       SSD1306 128x32，中英文混排，6 段大数字渲染

--------------------------------------------------------------------
稳定性设计
--------------------------------------------------------------------

  光判据直接比较 ADC 原始值。强光下分压饱和即放行，饱和点与电池
    电压无关，天然免疫电压漂移，也不依赖带隙补偿。
  按键中断服务程序只置一个标志，不再关闭自身中断源。EX0 全程保持
    使能——它是 STOP 唯一的唤醒源，关掉就只能拔电池。
  入睡改用低电平触发，手按着就一直是唤醒条件，不依赖「有没有那一个
    边沿」；醒来立刻切回下降沿，长按不会被当连击。
  冷启动先拉低总线泄放 250 ms，逼面板跌破 POR 门限真正复位。烧录、
    看门狗复位这类「面板一直有电」的重启全靠这一步，否则屏幕全黑。
    泄放之后每 5 ms 探一次 ACK，面板一应答就继续，最多等 300 ms。
  软件 I2C 逐字节检查 ACK，失败不重发——面板不在线时重发只会把
    整屏刷新拖成几秒黑屏，不如直接放弃这一帧。
  OLED 命令收敛为一张表，冷启动与唤醒共用；开屏时机交给调用方，
    保证「先画完再点亮」。
  EEPROM 用 7 字节记录：chk | merit[4] | mode | seq。校验字节最先
    写入，任何半写立刻被拒；双槽交替，另一槽永远是上一笔完整记录。
  ADC 电池与光照判定均剔除哨兵值，电池测不到时按「不关机」处理，
    避免一次异常读数导致反复关机。
  STOP 唤醒前显式置高按键端口锁存位，避免读改写导致唤醒电平被误判。
  随机数 LCG 增量取奇数（0x3B7B），满周期 65536，种子取自 ADC 噪声。
